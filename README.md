1. A database named Restaurant is created and selected for use.

2. The Customers table is defined to store each customer’s ID, name, phone number, and visit date.

3. Eleven customer records are inserted into the Customers table.

4. The Menu table is created to store all food items with their ID, name, and price.

5. Eleven menu items such as Burger, Pizza, and Pasta are added.

6. The Orders table is created to record every order placed by customers, including which customer made it, table number, time, and total amount.

7. Each order is linked to a customer through a foreign key, ensuring data consistency.

8. Eleven order records are inserted, each representing a different customer’s purchase.

9. The Order_Items table is made to track the specific items and quantities within each order.

10. It connects the Orders and Menu tables using foreign keys, representing a many-to-many relationship.

11. Eleven order-item entries are inserted, showing what items each order contained.

12. The Staff table is created to store employee information such as ID, name, role, phone, and hire date.

13. Eleven staff members (waiters, chefs, managers, etc.) are inserted into the Staff table.

14. The Payments table is made to record each payment, the amount, method (Cash, Card, UPI), and time.

15. Each payment links to a customer through a foreign key.

16. Eleven payment records are inserted corresponding to customers’ orders.

17. The Reservations table is created to keep track of table bookings — customer, time, table number, and number of people.

18. Eleven reservation records are inserted showing different customers’ bookings.

19. The project then includes fetching queries to display and analyze data, such as viewing all customers, sorting menu items, or listing high-value orders.

20. Some queries demonstrate WHERE, ORDER BY, GROUP BY, and HAVING clauses.

21. Others show JOINs between tables to combine customer, order, payment, and reservation data.

22. There are examples of aggregate functions like SUM, AVG, MIN, MAX, and COUNT to summarize information.

23. Queries also use DISTINCT, BETWEEN, LIKE, and LIMIT to filter or limit results.

24. Subqueries are used to find customers based on payment methods.

25. Several word problems with SQL solutions are included — each one applies the tables and relationships to answer business questions (e.g., total revenue, top-spending customers, reservation stats).

26. The project demonstrates creation of a fully connected relational database and practical SQL operations from beginner to advanced level.
